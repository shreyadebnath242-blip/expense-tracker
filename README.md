# Expense Tracker

A command-line app built in Python to log daily expenses and see where the money goes.

## Features
- Add an expense with a name, category and amount
- View all saved expenses
- See a category-wise summary with a total
- Data is saved in `expenses.json`, so it stays after closing the program

## How to run
1. Install Python 3
2. Download `expense_tracker.py`
3. Run `python expense_tracker.py` in a terminal
4. Pick an option from the menu

## What I learned
- Writing and organising code with functions
- Using lists and dictionaries to store data
- Reading and writing JSON files
- Handling invalid input with try/except
